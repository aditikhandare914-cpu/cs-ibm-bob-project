🔐 Password Scoring
  • 35-entry common-password blocklist → score 0
  • Length 16+ / 12+ / 8+ → +30 / +20 / +10
  • Each char type (U/L/D/Special) → +12 each
  • Shannon entropy > 4.0 → +15
  • Repeated characters → −10
  • Sequential patterns → −10

🔒 Privacy
🔒
Zero Data Collection

CyberShield runs entirely on your local machine. URLs, email content, and passwords you enter are processed in memory only for the duration of a single request and immediately discarded. No database is used. No analytics. Nothing is logged. The only network traffic is between your browser and 127.0.0.1:5000 — it never leaves your computer.
